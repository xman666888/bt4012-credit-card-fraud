# Rubric-aligned report outline

The final report is limited to 8-12 pages, excluding references and appendices.

1. **Problem description** - operational decision, stakeholders, fraud cost and constraints.
2. **Data overview** - source, license, schema, sample sizes, class balance and time range.
3. **Methodology** - preprocessing, leakage controls, features, model choices and rationale.
4. **Experimental design** - chronological split, tuning protocol, metrics and ablations.
5. **Results and applicability** - comparisons, threshold trade-offs, interpretation and
   proposed use in an investigation workflow.
6. **Limitations and future work** - synthetic-data validity, drift, fairness, privacy and
   external generalisation.
7. **Reproducibility** - environment, commands, seed, data version and GitHub URL.

Appendices may contain extended tables, hyperparameter ranges and supplementary plots.
References must include the dataset creators and any reused code or public notebooks.
