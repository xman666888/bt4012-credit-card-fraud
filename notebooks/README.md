# Notebook plan

Use numbered notebooks in this order:

1. `01_data_audit.ipynb` - schema, missing values, time range and class balance.
2. `02_exploratory_analysis.ipynb` - interpretable fraud patterns and visualisations.
3. `03_baselines.ipynb` - Dummy and Logistic Regression diagnostics.
4. `04_tree_models.ipynb` - Random Forest and boosting comparisons.
5. `05_threshold_and_explainability.ipynb` - threshold, cost and feature explanations.

Reusable transformations and metrics belong in `src/bt4012_fraud/`, not notebook cells.
